🎯 Project Objective
The objective of this project is to analyze e-commerce sales data using Power BI and uncover actionable business insights such as:

Sales performance across months and regions

Customer purchasing behavior

Product category trends

Payment method distribution

Profitability by sub-categories

This interactive dashboard helps decision-makers understand key metrics and make data-driven strategies to improve profitability and customer experience.

📁 Dataset Used
Source: Sample Superstore Dataset (adapted for e-commerce scenario)

Link: Download Dataset

The dataset contains order-level details including:

Customer info

Order date

Product categories

Sales, profit, quantity

Payment mode

State/Region

📊 Project Insights
🛒 Clothing is the most purchased category (68% of quantity).

🏆 Delhi leads in total sales amount.

💰 February generated the highest profit among all months.

💳 Cash on Delivery (COD) is the most preferred payment mode (48%), followed by UPI (22%).

👤 Customers like Mohanraj and Ajay contribute significantly to total revenue.

🔍 Bookcases and Phones drive the highest profit margins in their sub-categories.

🧾 Final Conclusion
This Power BI dashboard provides a comprehensive view of the business's sales and profitability, making it easier to:

Identify top-performing products and regions

Understand customer and payment trends

Optimize marketing and inventory strategies

This project demonstrates how data visualization can simplify complex datasets and uncover critical business insights in an intuitive format.
